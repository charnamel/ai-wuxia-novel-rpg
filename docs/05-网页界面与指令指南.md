# 网页界面与指令指南

写给玩家的操作手册：界面上每个按钮是干什么的、常用指令怎么写、骰子检定怎么触发。

## 界面布局

**电脑端**：左边是命令导航栏（按五类分组），中间是剧情阅读区，底部是行动输入框。

**手机端**：命令收纳进底部抽屉，点左下角「☰ 命令」展开；弹窗自动全屏。

## 常用指令写法

直接在底部输入框输入即可，按钮只是快捷方式，手打指令效果相同。

### 对战（战斗系统）

```
对战 角色名
```

- 挑战已有 NPC：`对战 胡斐`
- 挑战陌生人：`对战 黑衣刀客`（AI 现场生成对手档案）

**括号锁境界**——直接指定对手实力档位：

```
对战 黑衣人（略有小成）
```

14 档境界从低到高：初学入门 · 初窥门径 · 略有小成 · 略有所成 · 渐入佳境 · 融会贯通 · 登堂入室 · 炉火纯青 · 出神入化 · 登峰造极 · 超凡入圣 · 返璞归真 · 天人合一 · 破碎虚空

**括号线索**——括号里写非境界的描述，作为身份/门派/武功风格线索：

```
对战 神秘剑客（使剑，朝廷鹰爪）
```

**战斗流程**：

1. 开战后先选模式：`1` 比武切磋 / `2` 死斗 / `3` 暗中偷袭 / `4` 擂台竞技 / `5` 江湖群斗 / `6` 退出对战
2. 之后每轮直接输入出招动作，如：`一剑刺向对方胸口`
3. 战斗中随时可以输入 `结束对战`（AI 结算结局）或 `判局`（AI 分析当前战局）

### 存档 · 读档 · 删档

```
存档 存档名
读档 存档名
删档 存档名
```

示例：`存档 出门打猎前` → 之后 `读档 出门打猎前` 回到这个节点。点「存档 · 读档」按钮可查看现有存档列表。

### 调试指令

改 NPC 身体状态（支持：normal 轻伤 light_injured 重伤 heavy_injured 濒死 dying 死亡 deceased 中毒 poisoned）：

```
设置NPC状态 角色名 状态值 描述
设置NPC状态 仪琳 dying 被从二楼掷下，全身重伤
```

一键治愈：

```
治愈NPC 角色名 [描述]
治愈NPC 仪琳 伤势痊愈
```

### 遗忘功法 / 扔掉物品

```
遗忘功法 功法名
扔掉物品 物品名
```

两者都不可恢复，确认不需要再操作。

## 结构化输入：@角色 / #旁白

默认情况下，你写的每一句都算「**玩家（主角）自己的言行**」。如果要写**旁白**或**NPC 的台词/心理/动作**，用下面两个符号标记归属：

| 写法 | 含义 | 例 |
|---|---|---|
| `@角色名：内容` | 这段由该角色演出（是台词、心理还是动作，由 AI 按文义判断）| `@陆菲青：前辈，晚辈告辞。` |
| `#内容` | 旁白 / 环境叙述 | `#窗外雨声渐密` |
| 不加标记 | 玩家自己的言行（默认）| `推门进去看看` |

**要点**

- 输入框旁有 **`@`、`#` 两个快捷按钮**；打 `@` 会弹出 **NPC 候选下拉**，按「**在场 > 临时登场 > 全量名单**」排序，**前缀优先**，点一下即插入完整名字。
- `@` 后的名字会**自动匹配 NPC 名单**；**名单外的名字也支持**（自由名），但建议用 `：` 或 `，` 与内容隔开，如 `@黑衣人：你等着`。
- 想打**字面**的 `@` 或 `#`，写成 `\@`、`\#`。
- 多段可以混用，**顺序就是叙事顺序**：

```
@陆菲青：前辈好。
@玩家：晚辈告辞。
#窗外雨声渐密
```

- 在地图上选好目标地点后，系统会**自动注入**一行 `【场景目标】…`，不用手写。
- 效果：AI 不会再把「你写的 NPC 台词/心理」误当成玩家说的话；你可以像**导演**一样安排 NPC 的戏。
- 不写台词只写动作/心理也可以：`@黑衣人：冷笑一声，转身就走`，AI 会按文义判断。

> 战斗里另有 `（境界）` 写法（如 `对战 黑衣人（略有小成）`），与上面的 `@`/`#` 互不影响。

## 骰子检定怎么触发

输入里提到武功就会触发 d20 检定面板，确认后掷骰：

- **点名武功**：`我施展独孤九剑破他剑招` → 必定用独孤九剑判定
- **类型词**：`运起内力一掌拍向他` / `施展轻功跃上屋檐` → 自动匹配装备的内功/轻功
- **普通招式**：`一拳打过去` → 也会触发基础检定

检定匹配优先级：**点名的武功 > 装备槽里的内功/轻功 > 经验最高的同类型武功**。掷骰结果分 8 档（大成功→大失败），直接决定这一招的实际效果，AI 不能自说自话。

## 新手推荐流程

1. **创建角色**：填姓名、出身、本命功法（开场剧情会按你的档案生成）
2. **先点「地图」**：选个地点出门，在客栈、市集跟人搭话熟悉世界
3. **遇到冲突就「对战」**：找个低境界对手（如 `对战 地痞（初学入门）`）体验战斗和骰子
4. **累了就「练功」**：攒经验升境界，境界越高检定越强
5. **想跟原著剧情了**：点「回归主线」，玩完一段点「主线完成」推进下一段
6. **重要节点先「存档」**：大决定之前存一个，翻车了读档重来
