# DC 判定系统 · 原版存档与新方案

> 用途：本文档上半部分为**原版系统完整存档**（回滚依据），下半部分为**新版方案定稿**（C方案 + A选项 + 0.5版加成表 + 增幅封顶+10）。
> 改造目标：同级对决胜率从 ~95% 降到 60-70%，境界主导战力，末段（返璞~破碎）不失控。
> 状态：**已于 2026-09-08 实施完毕**，本地回归测试 34/34 通过（tool/test_dc_v51_rebalance.py），未部署服务器。

## 一、原版系统存档（回滚用）

### 1. DC 计算公式

```
总DC = 基础DC + 环境修正 + 战况修正 + 装备修正
```
- AI 分项填值，程序 `compute_final_dc()` 加总，AI 不心算总分
- 修正范围：环境 ±4 · 战况 ±3 · 装备 ±1（玩家有利为负）
- 基础DC：对战 = 对手当前实际境界查表；日常 = 行动固有难度
- 总分夹紧 `[5, 30]`
- 兜底DC：对战 14 / 日常 12（AI 解析全失败时）
- 铁律：DC 只取决于对手强度和环境，与玩家自身实力无关

**总修正公式**：
```
攻击总修正 = 基础修正 + 品阶加成 + 武功境界加成
总修正 = 攻击总修正 + 增幅值
判定值 = d20自然值 + 总修正
delta = 判定值 − DC
```
overall 通用行动只算基础修正，品阶/境界加成归零。

### 5. 增幅公式【原版：无封顶、int 截断】

```
内功增幅率 = (内功品阶加成 + 内功境界加成) / 25      全额
轻功增幅率 = 同公式 ÷ 2                               半额
增幅值 = 攻击总修正 × 增幅率，公平四舍五入（0.5进）
保底：增幅值为0且攻击总修正>0时，至少+1
总增幅 = 内功增幅 + 轻功增幅（无上限）
触发条件：主攻击武功 + 内功/轻功同时存在
```

## 二、新版方案定稿（C方案 + A选项 + 0.5版 + 封顶+10）

### 1. 四项核心决定

| 项 | 决定 | 效果 |
|---|---|---|
| DC 表重标 | 斜率 2→3，上限 30→40 | 同级胜率压进 60-70% |
| 加成表 | 0.5 版（品阶1~5步长0.5，境界0~7步长0.5） | 境界主导：升1境≈+1.5~2，升1品阶仅+0.5，权重比3:1 |
| 8档分级 | A 选项：仅 1/2/3 档阈值下移6点，4档 delta=0 保持 | 成败线不动，失败不被伪装成"没输"；赢的局大多落3档以上 |
| 增幅 | 封顶 +10 | 末段（返璞/天人/破碎）增幅滚雪球被削，同级 55/60/70% |

### 5. 浮点兼容改动（0.5 表的前置条件，必改）

`:+d` 格式说明符遇到 17.5 这类浮点值会直接抛异常，三处改为 `:+g`（int/float 双兼容，17.5→+17.5，18→+18）：
- check_d20 L104：`f"2d20{mode}{modifier:+d}"` → `:+g`
- check_d20 L108：`f"d20{modifier:+d}"` → `:+g`
- build_constraint_text_v4 L1988：`{total_modifier:+d}` → `:+g`
- build_constraint_text_v4 L1989：`{delta:+d}` → `:+g`（delta 也可能是浮点）

（面板将出现「总修正 +17.5」类显示，已确认可接受）
