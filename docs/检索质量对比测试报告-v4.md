## 二、关键发现

### 2.1 主动检索的最大价值：L4章节摘要命中翻倍

| 场景 | 被动L4 | 主动L4 | 主动检索关键词 |
|------|--------|--------|---------------|
| Round 1 | ✅ 少年入镖局 | ✅ 雏鹰试翼初入镖局 | "李三奇 六合刀 六合拳 练武 护院老周" |
| Round 245 | ✅ 铁门寨前探虚实 | ✅ 铁门寨前探虚实 | "铁雄 拦路索箱 铁门寨 铁门闩刀法" |
| Round 491 | ❌ 无 | ✅ 鸳鸯刀归隐，仁者无敌传佳话 | "萧中慧 赠刀 鸳鸯刀 萧家 缘由" |
| Round 932 | ❌ 无 | ❌ 无 | "霍青桐 定情 叶尔羌河 回疆 同往" |

被动检索只用玩家原始输入做query，输入过长导致语义被稀释，L4章节摘要命中率低（2/10）。主动检索生成聚焦关键词如"萧中慧 赠刀 鸳鸯刀 萧家 缘由"，向量匹配更精确，L4命中率翻倍（4/10）。

### 2.2 主动检索的NPC记忆联想优势

**Round 245示例**：
- 被动：只找到马行空的记忆（因为他出现在玩家输入中）
- 主动：生成了"袁依依 鸳鸯刀 暗中跟随 护镖"→ 找到袁依依的NPC记忆

小模型通过近期剧情摘要知道袁依依在暗中跟随，主动生成了她的检索关键词，找到了被动检索完全遗漏的记忆。

### 2.3 被动检索的稳定优势：NPC记忆全覆盖

被动检索用完整玩家输入做query，虽然L4命中率低，但NPC记忆命中率100%（10/10场景至少找到1条）。因为玩家输入中提到的人名会被向量库语义匹配到该NPC的记忆。

主动检索有时因为关键词过于聚焦反而漏掉了某些NPC记忆（6/10场景有NPC命中）。

### 2.4 两个失败场景分析

**Round 686（"不想走镖"）**：JSON解析失败，小模型生成的tool call参数被截断。
**Round 1176（"师父，当然是……报官咯"）**：玩家输入仅7字，小模型认为信息不足未调用tool。

这两个场景占20%，需要增加fallback逻辑：主动检索失败时自动回退到被动检索结果。

### 2.5 耗时分析

主动检索平均9.54s，构成：
- 小模型思考：4-7s（主延迟来源）
- 并行3组云向量检索：2-3s
- 二次校验：2-3s

对比被动2.68s，主动延迟增加约7s。如果与DC判断并行执行，实际增量延迟仅为检索+校验的5s左右。

## 四、结论与建议

### 4.1 主动检索云向量的价值

| 价值点 | 评价 | 证据 |
|--------|------|------|
| L4章节摘要命中 | ★★★★ 翻倍 | 2/10→4/10 |
| NPC记忆联想 | ★★★ 可补充 | 主动找到被动遗漏的NPC |
| 语义聚焦 | ★★★★★ | 短关键词比长输入匹配更精准 |
| 稳定性 | ★★★ | 2/10失败需fallback |

### 4.2 推荐的混合策略

```
玩家输入
    │
    ├──→ 世界书被动检索（2-3s，始终执行）
    │
    ├──→ 云向量被动检索（2-3s，始终执行）
    │         └──→ 稳定基线：NPC记忆全覆盖
    │
    └──→ 云向量主动检索（与DC并行，~10s）
              ├──→ 小模型生成关键词
              ├──→ 并行3组向量检索
              ├──→ 去重
              ├──→ 校验（可选）
              └──→ 失败时回退到被动结果
```

**合并规则**：
1. 世界书：只用被动结果
2. 云向量：被动结果为基础 + 主动结果去重后追加
3. 主动检索失败时：完全使用被动结果（无感降级）
4. 主动检索超时（>15s）：只取已完成的部分结果

### 4.3 下一步

1. **增加fallback**：主动检索失败时自动回退被动结果
2. **降低小模型延迟**：思考prompt精简，max_tokens从800降到600
3. **优化校验**：接受40%成功率作为可选增强，不阻塞主流程
4. **进入分支开发**：可以开始 `feature/parallel-thinking-retrieval`
