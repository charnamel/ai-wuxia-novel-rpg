# 世界书检索引擎详解（worldbook.py）

世界书是本游戏的「静态知识库检索系统」：游戏内置约 2200 条武侠世界设定（人物、武功、门派、地点、物品、主线剧情），每轮剧情生成前，引擎根据当前对话内容检索相关条目，按需注入 AI 上下文——**AI 只带需要的世界知识上场**，既保证剧情符合设定，又避免上下文爆炸。

---

## 1. 六大数据源 → 六大输出类

| 数据源文件 | 输出类 | 条目数 | 说明 |
|-----------|--------|--------|------|
| `data/mainline_catalog.json` | 【①任务】 | 89 | 主线剧情节点（闯王宝藏、鸳鸯刀传说等） |
| `data/npc_agents.json` | 【②NPC】 | 276 | 人物档案（身份、性格、秘密、初始好感） |
| `data/martial_arts_bonus.json` | 【③武功】 | 665 | 武功招式（仅收录 grade≥3 的高品阶武功） |
| `data/items_catalog.json` | 【④物品】 | 870 | 兵器丹药秘籍（含稀有度 S~D 分级） |
| `data/timeline_reference.json` | 【⑤门派】 | 43 | 门派势力（武当、红花会、药王门等） |
| `data/map_data.json` | 【⑥地点】 | 275 | 世界地图（区域→聚落→地点三级嵌套） |

合计 **2218 条目、8788 个关键词**，索引构建仅需约 250ms。

## 2. 索引结构

引擎启动后（懒加载：首次检索时才构建）在内存中建立三类索引：

- **倒排索引**：`关键词 → 条目ID集合`，支持关键词精确命中
- **标题索引**：`标题 → 条目ID`，支持标题精确命中
- **年代索引**：`年份 → 条目ID集合`，支持按剧情年代加权
- 中文标题额外做 **2-gram 切分** 补入倒排索引（「降龙十八掌」→「降龙」「龙十」「十八」「八掌」），提升模糊命中

**自动更新**：每次检索前检查 6 个数据文件的 mtime，任一文件被修改即自动重建索引（5 秒节流防抖动）。改数据文件后无需重启游戏。

## 3. 五层检索打分（L1~L5）

每次检索的 Query 是「上一轮 AI 完整输出 + 玩家最新输入」，五层并行打分累加：

| 层 | 匹配方式 | 单次得分 | 说明 |
|----|---------|---------|------|
| L1 | 标题精确匹配 | **×10** | Query 中出现完整条目标题（如「苗人凤」三字）即重分命中 |
| L2 | 关键词精确匹配 | ×1 | Query 中出现条目 keywords；长文本（>200字）时只算 3 字以上关键词，避免短词刷分 |
| L3 | 模糊子串匹配 | 0.05~0.3 | 中文 2/3-gram 与条目标题/关键词/内容互查；按类别设权：任务/NPC 0.3，门派 0.2，武功/地点 0.15，**物品 0.05**（870 条物品 gram 极易刷屏，特意压到最低） |
| L4 | 年代范围匹配 | ×0.5 | 条目 year_range 覆盖当前游戏年份时加权（剧情推进有时间感） |
| L5 | 语义向量匹配 | sim×2.0 | 本地 embedding 模型计算余弦相似度，相似度 >0.45 的前 30 条计入；能命中「辽东大侠」→胡一刀、「会医术的人」→程灵素这类**无共同字的语义关联**（详见 [03-本地语义向量检索.md](03-本地语义向量检索.md)） |

物品类条目还有**稀有度权重**叠加：S 级 ×3.0、A 级 ×2.0、B 级 ×1.2、C 级 ×0.8、D 级 ×0.4——屠龙刀天然比普通铁剑更容易被检索到。

## 4. 排序与输出控制

打分后按三键排序：`priority（降序）→ score（降序）→ weight（降序）`，再做四道流量控制：

1. **分数门槛**：score < 1.5 的条目直接过滤（L1 命中=10 分稳过；纯 L3 gram 噪声需 5 个以上 gram 才能过线）
2. **必选条目保底**：priority=1 的条目（核心设定）即使零得分也保底 0.5 分进入候选
3. **每类槽位上限**：NPC 8 条、任务 6、武功 6、物品 6、门派 4、地点 5——保证六类知识均衡，不被单一类刷屏
4. **每类字数配额**（总上限 2000 字）：NPC 25% / 物品 20% / 任务 15% / 武功 15% / 门派 15% / 地点 10%；某类配额未用完时按「NPC→任务→门派→武功→地点」优先级溢出补给

最终输出形如：

```
【②NPC】
【苗人凤】|外号「金面佛」…打遍天下无敌手…
【胡斐】|雪山飞狐…
【③武功】
【苗家剑法】|…
【⑥地点】
【玉笔峰】|辽东…
```

空结果返回空字符串，任何内部异常也安全降级返回空——**世界书永不阻塞主流程**。

## 5. 设计原则

- **零侵入**：主程序只需 `import worldbook` 后调用 3 个函数（`init()` / `search()` / `get_status()`），模块缺失时 try/except 自动跳过
- **懒加载**：导入零耗时，首次检索才建索引
- **自动更新**：数据文件改动即时生效
- **安全降级**：语义检索（L5）未安装依赖时自动退化为 L1~L4 纯关键词检索，功能完整
- **性能**：全流程内存检索，单次 <5ms（不含 L5 语义层；L5 首次查询约几十毫秒）

## 6. 如何扩展世界书

- **修改/新增 NPC**：编辑 `data/npc_agents.json` 的 `npc_list[]`，每条含 `name`（将作为标题）、`identity/personality/secret` 等（拼接为 content）、可选 `keywords[]`（主动补充检索关键词）
- **新增武功/物品/地点**：对应修改 `martial_arts_bonus.json` / `items_catalog.json` / `map_data.json`，格式参照文件内已有条目
- 保存后无需重启，下轮检索自动用新数据（mtime 检测）
- 若启用了语义检索，运行 `python build_semantic_index.py` 增量更新向量（只编码新增/变更条目）

## 7. 对外 API 速查

```python
import worldbook

worldbook.init()                # 初始化（懒加载标记）
result = worldbook.search(      # 检索（首次调用自动建索引）
    text,                       # Query：上一轮AI输出+玩家输入
    current_year=1780,          # 可选：当前游戏年份（触发L4）
    top_k=24,                   # 最大候选条目数
    max_chars=2000              # 输出字数上限
)
worldbook.rebuild()             # 手动强制重建索引
worldbook.get_status()          # 状态查询（Web端面板用）
```
