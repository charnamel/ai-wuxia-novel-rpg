# 部署指南

从零把游戏跑起来。整个过程大概十分钟，主要时间花在装依赖和下载模型上。

## 1. 环境要求

- 操作系统：Windows / Linux / macOS 都可以
- Python 3.10 及以上
- 硬件：普通 PC 就行，不需要显卡。开语义检索的话留 500MB 左右空闲内存
- 网络：能访问一个 OpenAI 兼容的 LLM API

需要的 API Key（最少一个就能玩）：

- **必填**：LLM API Key。两个推荐选择：
  - DeepSeek 官方（platform.deepseek.com）：注册后充几块钱够玩很久，最省事
  - OpenCode Go（opencode.ai）：一个密钥能调 deepseek-v4-flash / gpt-5.6-luna / grok-4.5 等多种模型，适合想换着玩的
- 可选：阿里云百炼 Key（云端长期记忆）、SiliconFlow Key（NPC 头像与剧情配图）

## 2. 部署步骤

### 2.1 获取代码并安装依赖

```bash
git clone https://github.com/charnamel/ai-wuxia-interactive-novel.git
cd ai-wuxia-interactive-novel

python -m venv venv
# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
```

依赖分两组：

- 核心依赖（flask、openai、requests 等）：不大，必装
- 语义检索依赖（sentence-transformers、numpy）：带 torch，体积比较大。不装也能玩，游戏会自动降级成纯关键词检索，只是检索效果差一些

### 2.2 配置 API Key

```bash
# Windows
copy .env.example .env
# Linux / macOS
cp .env.example .env
```

编辑 `.env` 填入密钥。最小可用配置只要两处（主循环和辅助模型可以用同一家）：

```ini
MAIN_LOOP_A_API_KEY=sk-xxxx
AUX_A_API_KEY=sk-xxxx
```

主循环模型负责生成剧情，辅助模型负责状态提取和骰子判定，都是必填。

用 OpenCode Go 的话，把密钥填进 `MAIN_LOOP_B_API_KEY` 和 `AUX_B_API_KEY`，再把 `MAIN_LOOP_ACTIVE` 和 `AUX_ACTIVE` 改成 `B`。

其他配置全是可选的：

- `IMG_GEN_*`：剧情配图模型，不填就没有配图
- `DASHSCOPE_API_KEY` + `BAILIAN_PLOT_MEMORY_ID`：云端长期记忆，不填记忆全在本地
- `KOLORS_IMG_API_KEY`：NPC 头像和配图生成，不填用内置的 276 张头像

各配置项的说明在 `.env.example` 里都有注释。

### 2.3 预构建语义向量索引（可选，推荐）

这步把世界书两千多条目提前编码成向量缓存，游戏内检索零等待：

```bash
pip install sentence-transformers numpy    # 上一步没装的话
python build_semantic_index.py
```

几个要点：

- 首次运行要联网下载 embedding 模型（约 95MB，已配置国内镜像 hf-mirror.com）
- 全量编码约 1~3 分钟（看 CPU），生成 `data/semantic_vectors.npy`（约 4.5MB）
- 之后运行直接加载缓存，秒级完成
- 改了世界书数据后再跑一遍就是增量更新，只编码新增和变动的条目

跳过这步的后果：游戏里第一次触发语义检索时会临时编码，卡 30 秒到 2 分钟，之后自动缓存。想彻底不用语义检索，`.env` 里 `ENABLE_SEMANTIC_SEARCH=false` 即可。

### 2.4 启动游戏

```bash
python run.py
```

看到下面的输出就说明起来了：

```
==================================================
  NEW6 - AI武侠互动小说
  访问地址: http://localhost:5000
==================================================
```

浏览器打开 **http://localhost:5000**，点「创建角色」开始玩。手机连同一个局域网也能访问（监听 0.0.0.0）。

## 3. 服务器部署

长期挂服务器上跑的话：

```bash
pip install gunicorn
gunicorn -w 1 -b 0.0.0.0:5000 --timeout 300 run:app
```

三个注意点：

- **worker 数必须是 1**。游戏状态存在本地 JSON 文件里，多 worker 会互相覆盖数据
- **timeout 给足**（300 秒以上）。AI 生成剧情慢，超时太短请求会被杀掉
- 建议配 systemd 或 supervisor 做进程守护；前面挂 Nginx 反代的话，超时同样调到 300 秒以上

## 4. 常见问题

**启动提示 `MAIN_LOOP_A_API_KEY 未设置`**
检查 `.env` 文件是不是在项目根目录，密钥有没有填对。程序启动时只从 `.env` 读配置。

**API 报 403**
一般是密钥无效，或者厂商限制了你的地区（部分海外厂商对部分地区不开放）。换个 Key 或换家厂商试试。

**API 报 400**
多半是模型名写错了。对照厂商的模型列表，核对 `.env` 里的 MODEL 字段拼写。

**日志出现 `[语义检索] 未启用`**
正常降级，不是报错。想启用：装 sentence-transformers 和 numpy，`.env` 里 `ENABLE_SEMANTIC_SEARCH=true`，跑一遍 `python build_semantic_index.py`。

**build_semantic_index.py 下载模型失败**
检查网络，确认能访问 hf-mirror.com；有代理的话设好代理环境变量再重试。模型只需要下载一次，之后完全离线。

**云端记忆怎么开**
注册阿里云百炼，在控制台「记忆管理」里创建一个记忆库，拿到 mem- 开头的 ID，和 DASHSCOPE_API_KEY 一起填进 `.env`。不开的话记忆全在本地，游戏功能完整。

**怎么重置游戏进度**
停掉程序，删掉 `data/` 下的 player.json、game_save.json、interact_log.jsonl 这些运行时文件（npc_agents.json、map_data.json 等静态数据别删），重启就是新游戏。
