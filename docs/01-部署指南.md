# 部署指南

本文档介绍如何从零部署 AI 互动武侠小说游戏，包括环境准备、依赖安装、API 配置、语义向量索引预构建与服务器部署。

---

## 1. 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows / Linux / macOS 均可 |
| Python | 3.10 及以上 |
| 硬件 | 普通 PC 即可（启用语义检索需约 500MB 空闲内存） |
| 网络 | 需访问一个 OpenAI 兼容的 LLM API |

需要的 API Key（最少 1 个即可游玩）：

- **必填**：一个 LLM API Key（推荐 [DeepSeek 官方](https://platform.deepseek.com) 或 [OpenCode Go](https://opencode.ai)）
- 可选：阿里云百炼 Key（云端长期记忆）、SiliconFlow Key（NPC 头像与配图生成）

---

## 2. 部署步骤

### 2.1 获取代码

```bash
git clone https://github.com/charnamel/ai-wuxia-interactive-novel.git
cd ai-wuxia-interactive-novel
```

### 2.2 创建虚拟环境并安装依赖

```bash
python -m venv venv

# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
```

依赖说明：

- **核心依赖**（必装）：flask、openai、colorama、requests、python-dotenv、Pillow
- **语义检索依赖**（可选）：sentence-transformers、numpy —— 体积较大（含 torch），未安装时游戏自动降级为纯关键词检索，不影响游玩

### 2.3 配置 API Key

```bash
# Windows
copy .env.example .env
# Linux / macOS
cp .env.example .env
```

编辑 `.env`，填入你的密钥。`.env.example` 中提供了两组示例配置：

| 方案 | 适用 | 填法 |
|------|------|------|
| DeepSeek 官方 | 只想最快跑起来 | 注册 [platform.deepseek.com](https://platform.deepseek.com) 充值几元，把密钥填入 `MAIN_LOOP_A_API_KEY` 和 `AUX_A_API_KEY` |
| OpenCode Go 聚合网关 | 想用多种模型 | 注册 [opencode.ai](https://opencode.ai)，一个密钥可调用 deepseek-v4-flash / gpt-5.6-luna / grok-4.5 等，填入 `MAIN_LOOP_B_API_KEY` 后把 `MAIN_LOOP_ACTIVE` 改为 `B` |

最小可用配置只需填两处（主循环 + 辅助可以用同一家）：

```ini
MAIN_LOOP_A_API_KEY=sk-xxxx
AUX_A_API_KEY=sk-xxxx
```

其余（配图、云记忆、头像生成）全部可选，不填游戏照常运行。

> 详细配置项说明见 `.env.example` 内注释。

### 2.4 预构建本地语义向量索引（可选，推荐）

本步把世界书约 2200 条条目提前编码为向量缓存，让游戏内的语义检索零等待：

```bash
pip install sentence-transformers numpy   # 若上一步已装可跳过
python build_semantic_index.py
```

- 首次运行需联网下载 embedding 模型（BAAI/bge-small-zh-v1.5，约 95MB，已配置国内镜像）
- 全量编码约 1~3 分钟（视 CPU 而定），生成 `data/semantic_vectors.npy`（约 4.5MB）
- 之后再运行会直接加载缓存，秒级完成
- 数据文件更新后（如替换 npc_agents.json）重新运行即可**增量更新**，只编码新增/变更条目

跳过本步的后果：首次进入游戏触发检索时会临时编码（卡 30 秒~2 分钟），之后自动缓存。

### 2.5 启动游戏

```bash
python run.py
```

看到如下输出即启动成功：

```
==================================================
  NEW6 - AI武侠互动小说
  访问地址: http://localhost:5000
==================================================
```

浏览器访问 **http://localhost:5000**，点击「创建角色」即可开始游玩。

## 3. 服务器部署（长期运行）

```bash
pip install gunicorn
gunicorn -w 1 -b 0.0.0.0:5000 --timeout 300 run:app
```

注意事项：

- **worker 数必须为 1**：游戏状态存于本地 JSON 文件，多 worker 会产生数据竞争
- `--timeout 300`：AI 生成剧情可能较慢，避免请求超时被杀
- 建议配合 systemd / supervisor 做进程守护
- 若用 Nginx 反向代理，注意把超时也调到 300 秒以上

## 4. 常见问题

**Q: 启动时提示 `MAIN_LOOP_A_API_KEY 未设置`？**
A: 检查 `.env` 文件是否存在于项目根目录，密钥是否填写正确。程序从 `.env` 读取全部配置。

**Q: 玩起来正常，但日志出现 `[语义检索] 未启用`？**
A: 这是正常降级。想启用语义检索：`pip install sentence-transformers numpy`，`.env` 中设置 `ENABLE_SEMANTIC_SEARCH=true`，然后运行 `python build_semantic_index.py` 预构建缓存。

**Q: `build_semantic_index.py` 报模型下载失败？**
A: 检查网络；国内网络确认能访问 hf-mirror.com；也可设置代理环境变量后重试。模型只需下载一次。

**Q: API 报 400 / 403 错误？**
A: 403 多为密钥无效或区域受限（部分厂商限制地区）；400 多为模型名拼写错误，核对 `.env` 中的 `MODEL` 字段与厂商模型列表一致。

**Q: 云端记忆怎么开启？**
A: 注册阿里云百炼 → 「记忆管理」创建记忆库 → 把 `DASHSCOPE_API_KEY` 和 `BAILIAN_PLOT_MEMORY_ID` 填入 `.env`。不开启则全部记忆保存在本地，功能完整可用。

**Q: 如何重置游戏进度？**
A: 停止程序后删除 `data/` 下的运行时文件（player.json、game_save.json、interact_log.jsonl 等），重启后从新建角色开始。静态数据文件（npc_agents.json、map_data.json 等）不要删。
