# 本地语义向量检索

semantic_index.py 是世界书的一个增强层，解决关键词检索的短板：字面对不上就搜不到。

比如你说"那位辽东大侠"，关键词检索找不到任何东西——字面里没有"胡一刀"三个字。语义检索把文本编码成向量再比对相似度，绰号、描述、换种说法都能命中。

## 原理

用一个本地跑的中文小模型（BAAI/bge-small-zh-v1.5，约 95MB，CPU 就够）把世界书两千多条目都编码成向量，存成磁盘缓存。查询时把输入也编码一下，跟整个向量矩阵算余弦相似度，过阈值的条目按分数计入世界书检索结果，跟关键词得分一起排序。

## 怎么开

```bash
pip install sentence-transformers numpy
python build_semantic_index.py
```

`.env` 里 `ENABLE_SEMANTIC_SEARCH=true`。

首次运行要联网下模型（走了国内镜像），全量编码大概一分钟，之后走缓存，完全离线。建议部署完先跑一遍这个脚本，不然游戏里第一次触发检索会卡一阵。

## 几个特点

- 编码结果缓存在 `data/semantic_vectors.npy`，改了世界书数据再跑一遍脚本，只重新编码变动的条目
- 相关依赖挺大（带 torch），不装也不影响游戏，自动退回纯关键词检索
- 出任何异常都是静默降级，不会把游戏搞挂

## 和云端记忆的区别

本地语义检索查的是静态设定（NPC 是谁、武功什么样），云端记忆（阿里云百炼）存的是你的游戏经历（你干过什么）。一个让 AI 懂世界，一个让 AI 记得你。
